# MEIWA SOP Center

Static GitHub Pages site for internal MEIWA SOPs.

## Pages

- `/` — SOP selector
- `/fuel/` — SOP การส่งรูปเติมน้ำมัน
- `/photo-standard/` — SOP มาตรฐานการถ่ายรูปงานบริการ

## Deploy

This project is static HTML/CSS/JS and can be deployed directly with GitHub Pages.

```bash
git add .
git commit -m "refactor: redesign SOP portal and service photo standard"
git push
```

The Fuel SOP content is kept unchanged; this revision updates the portal and Service Photo SOP only.
